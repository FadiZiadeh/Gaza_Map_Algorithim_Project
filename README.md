# Gaza Map – Shortest Path Finder

A **JavaFX-based interactive map application** that models the **Gaza Strip's locations and road network** as a weighted graph. The project allows users to select locations on the map and find the **shortest route between them** using **Dijkstra's Algorithm**.

The application represents different locations across Gaza as graph nodes and the roads connecting them as weighted edges, where the weights represent the distance between locations. Dijkstra's algorithm is then used to calculate the optimal path from a selected starting point to a destination.

### Features

* 🗺️ Interactive **map of the Gaza Strip** built using JavaFX.
* 📍 Multiple Gaza locations represented as points on the map.
* 🛣️ Roads connecting the different locations.
* ⚖️ Weighted roads based on distances between locations.
* 🔎 Selection of a starting location and destination.
* 🚗 Calculates the shortest route using **Dijkstra's Algorithm**.
* 📏 Displays the total distance of the calculated route.
* 🎨 Visual representation of the selected shortest path on the map.
* 🖥️ Graphical User Interface developed entirely with **JavaFX**.

### Algorithms & Data Structures

The project applies fundamental concepts of **graph theory**, including:

* Weighted graphs
* Vertices and edges
* Adjacency relationships
* Shortest-path algorithms
* **Dijkstra's Algorithm**

### Technologies

* **Java**
* **JavaFX**
* Graph Data Structures
* Dijkstra's Shortest Path Algorithm

### Project Objective

The goal of the project was to demonstrate how a shortest-path algorithm can be applied to a real-world geographical problem by creating a simplified digital representation of **Gaza's road network** and using Dijkstra's Algorithm to determine the most efficient route between locations.
